# CV — Malang Kiya Cissé

CV professionnel au format A4, conçu d'abord pour l'impression et l'export PDF.

## Structure

- `index.html` : contenu du CV
- `css/style.css` : mise en page A4 et styles d'impression
- `assets/photo.jpg` : photo personnelle à ajouter

## Palette

- Bleu pétrole : `#164E63`
- Bleu : `#2563EB`
- Gris ardoise : `#334155`
- Gris secondaire : `#64748B`
- Gris clair : `#F1F5F9`

Aucun noir pur n'est utilisé dans la charte.

## Utilisation

1. Ajouter la photo dans `assets/photo.jpg`.
2. Ouvrir `index.html` dans le navigateur.
3. Vérifier la mise en page.
4. Imprimer en choisissant **A4** puis **Enregistrer au format PDF**.
